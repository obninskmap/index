# Научный Обнинск — интерактивный атлас

Статический сайт о четырёх организациях: ФЭИ, ОНПП «Технология», НПО «Тайфун» и обнинской площадке НИФХИ им. Карпова. Тематическая подборка включает 24 примера разработок и 25 локальных изображений.

Опубликованный адрес: https://obninskmap.github.io/index/ . Локальные изменения требуют отдельной публикации.

## Возможности

Поиск по названию, адресу, исследованиям, разработкам, терминам и профессиям. Тематические фильтры синхронизируют список, метки и счётчики. Карта улиц переключается на спутник; обзор показывает найденные организации. На телефоне доступны представления «Список / Карта». Карточки открываются нажатием, разворачиваются для чтения и содержат галерею, источники, адрес и действия копирования.

[Каталог](catalog.html) читается без сети. [Страница проекта](project.html) содержит материалы для защиты. Координаты обозначают территории, а не проверенные проходные; фотографии могут быть архивными. Подложка карты и внешние ссылки требуют интернета. Без загрузки Manrope используется Arial или системный sans-serif.

## Локальный запуск

В корне проекта выполните `python -m http.server 8000` и откройте http://localhost:8000/ . Каталог также можно открыть непосредственно из файла. Сборка, база данных и API-ключи не нужны.

## Структура

| Путь                     | Назначение                                         |
| ------------------------ | -------------------------------------------------- |
| `index.html`             | Интерактивная карта                                |
| `catalog.html`           | Автономный каталог                                 |
| `project.html`           | О проекте и скачивание материалов                  |
| `assets/css/common.css`  | Общая палитра, шрифт, навигация и базовые элементы |
| `assets/css/style.css`   | Карта, карточки и галерея                          |
| `assets/css/project.css` | Каталог и страница проекта                         |
| `assets/js/app.js`       | Поведение интерфейса                               |
| `assets/js/data.js`      | Сведения об организациях                           |
| `assets/js/photos.js`    | Фотографии, подписи и источники                    |
| `images/`                | Локальные фотографии и герб                        |
| `vendor/`                | Leaflet и его лицензия                             |
| `materials/current/`     | Материалы, доступные со страницы проекта           |
| `materials/source/`      | Исходная презентация с пользовательскими правками  |
| `materials/archive/`     | Предыдущая сохранённая версия презентации          |
| `tests/`                 | Проверки и модель DOM                              |

В `materials/current/` сохранены `Карта_Обнинска_obninskmap.pptx`, `Пояснительная_записка.pdf` и `Пояснительная_записка.html`. Исходник `Карта_Обнинска.pptx` находится в `materials/source/`; версия `Карта_Обнинска_обновлённая.pptx` — в `materials/archive/`. Актуальная версия определена по существовавшим ссылкам сайта. Документы при переносе не редактировались.

`.build/`, `.playwright-cli/`, `output/playwright/`, `.vscode/`, `node_modules/` и временные файлы исключены из Git. Скриншоты проверки не являются материалами для защиты.

## Проверки

Нужен Node.js, установка зависимостей не требуется:

```powershell
node tests/test-verification.js
```

Проверяются синтаксис, безопасный вывод текста, поиск, карточки, прямые ссылки, копирование, мобильные представления, счётчики, обзор результатов и локальные ссылки. При ошибке команда завершается с ненулевым кодом.

Дополнительно проверяйте сайт в браузере на ширинах 360, 390, 768, 1280 и 1440 px: карточки и галерею, клавиатуру, отсутствие горизонтальной прокрутки, отказ подложки и чтение каталога без сети. Модель DOM не заменяет проверку в браузере.

## Добавление организаций

1. Добавьте запись в `assets/js/data.js`, используя существующие поля: уникальный `id`, группу, адрес, координаты, описания и источники.
2. Поместите фотографии в `images/`, добавьте подписи и источники в `assets/js/photos.js`. Пути задаются относительно HTML-страницы: `images/example.jpg`.
3. Обновите автономный каталог и показатели страницы проекта. Каталог хранит тексты непосредственно в HTML и не генерируется при открытии.
4. Запустите проверки и откройте `index.html#id` в браузере.

## Публикация

Сохраните структуру папок и `.nojekyll`, разместите файлы в репозитории и включите GitHub Pages для корня ветки `main`. Внутренние ссылки относительные и работают в подкаталоге. Публикация выполняется отдельно от локальной проверки. При изменении CSS/JS обновляйте параметры версий в HTML для сброса браузерного кеша.
